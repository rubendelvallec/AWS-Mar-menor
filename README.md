Guia de replicacion -> Guia para construir el proyecto desde 0 en AWS.
Memoria del proyecto.
proy-comandos-CLI -> Comandos necesarios para empaquetar una aplicación web en un contenedor Docker y subirla a AWS.
proy-funcion-notificacion -> Codigo necesario para implementar sistema de alertas.
proy-funcion-procesador-datos -> Codifo necesario para limpiar y guardar los datos correctamente en el bucker S3.
proy-funcion -> Codigo que incluye las diferentes metricas que podremos realizar a traves de nuestro navegador web.
proy_plantilla -> Plantilla para crear sistema de redes y grupos de seguridad asi como conexion a internet.
requirements -> Requerimientos.
